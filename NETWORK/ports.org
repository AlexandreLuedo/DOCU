#+title: Ports
#+LANGUAGE: en
* Definition
Ports are access points who make the link between client and server instances. You have multiples ports for each physicial/virtual machines.
* Named ports
| Port | Service                   |
|------+---------------------------|
|   20 | FTP datas                 |
|   21 |  FTP protocol            |
|   22 | ssh                       |
|   23 | telnet (sending mail)     |
|   25 | smtp (sending mail)       |
|   53 | DNS                       |
|   80 | HTTP                      |
|  110 | pop3 (get mail)           |
|  123 | NTP                       |
|  139 | netbios (service windows) |
|  143 | imap                      |
|  161 | snmp                      |
|  162 | traps snmp                |
|  389 | ldap (not secure)         |
|  443 | https                     |
|  465 | smtps (smtp on SSL)       |
|  514 | syslog                    |
|  636 | ldaps (ldap on SSL)       |
|  993 | imaps (imap on SSL)       |
|  995 | pop3s (pop3 on SSL)       |
* Listening all opened and used ports
#+begin_src bash :eval no
sudo lsof -i -n -P | grep LISTEN
