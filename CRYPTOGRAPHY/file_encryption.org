#+title: File Encryption
* Using gpg
See also : [[https://www.gnupg.org/gph/en/manual/x110.html][Encrypting Encrypting and decrypting documents]]
#+begin_quote
Standart for encrypting files
#+end_quote
** Encrypt
#+begin_src bash
gpg --symmetric --cipher-algo AES256 filename.txt
#+end_src
** Decrypt
#+begin_src bash
gpg --decrypt --symmetric --cipher-algo AES256 filename.txt.gpg > filename.txt
#+end_src
* Using openssl enc
So a long command
#+begin_src bash
openssl enc -aes-256-cbc -salt -pbkdf2 -iter 100000 -in input.txt -out output.enc -pass pass:your_password
#+end_src
